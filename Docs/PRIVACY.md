# Приватность

Lang Switcher обрабатывает ввод локально.

Приложение:

- не выполняет сетевых запросов;
- не включает updater, аналитику, рекламу или crash uploader;
- не читает и не изменяет clipboard;
- не сохраняет набранные слова и выделенный текст;
- не работает в Secure Input и защищённых полях;
- хранит только настройки и явно добавленные пользователем словарные правила.

Опциональная диагностика использует Unified Logging macOS и содержит только обезличенные идентификаторы операций, числовые размеры, длительности и коды ошибок. Физические key codes также не журналируются, поскольку по их последовательности можно восстановить текст.

macOS может локально создавать собственные системные crash reports. Lang Switcher не читает и не отправляет их.

Скрипт `Scripts/check-privacy.sh` проверяет исходники и манифест на известные сетевые и телеметрические API.
