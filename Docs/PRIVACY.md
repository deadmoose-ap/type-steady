# Безопасность данных, приватность и разрешения

## Краткая гарантия

TypeSteady обрабатывает клавиатурный ввод внутри локального процесса. В проекте нет сетевого клиента, updater, телеметрии, рекламы, аналитического SDK или crash uploader. Clipboard не читается и не изменяется.

При этом приложение технически получает чувствительные системные разрешения. Этот документ объясняет, что именно оно видит, зачем это необходимо и какие остаются ограничения.

## Какие данные попадают в процесс

Во время обычной работы в оперативной памяти кратковременно присутствуют:

- физические key codes текущего слова;
- состояния Shift и Caps Lock;
- две локально построенные версии слова в выбранных раскладках;
- разделитель после слова;
- выбранный через Accessibility текст на время его преобразования;
- PID и bundle identifier активного приложения;
- данные последней коррекции для короткого undo.

Текущее слово очищается при границе или потере достоверного контекста. Последняя ручная кандидатура живёт максимум 12 секунд. Undo доступен максимум восемь секунд и удаляется при следующем обычном вводе, клике или смене приложения.

## Что сохраняется между запусками

Через стандартный `UserDefaults` сохраняются только:

- включённость приложения и отдельных функций;
- выбранная агрессивность;
- выбранные English/Russian input source IDs;
- пресет горячей клавиши;
- настройки звука, overlay, диагностики и IDE-профиля;
- введённые пользователем списки «всегда исправлять» и «никогда не исправлять»;
- исключённые пользователем bundle identifiers.

Пользовательские списки являются явным вводом в настройках. Автоматически набранные слова в них не добавляются.

Встроенные словари находятся внутри `.app` как read-only resources. Системная проверка использует локальный `NSSpellChecker` macOS. Приложение не создаёт собственную историю ввода или базу исправлений.

## Диагностические данные

Диагностика выключена по умолчанию. При включении используется Unified Logging macOS.

Допустимые поля:

- фиксированный тип операции;
- число символов;
- числовой код результата;
- количество доступных раскладок.

Logger API не принимает слово, выделение или массив key codes. Запрещено журналировать:

- набранные символы;
- исходный и исправленный текст;
- выделение;
- Unicode scalars;
- физическую последовательность клавиш;
- clipboard.

Скрипт `Scripts/check-privacy.sh` проверяет Swift-исходники и `Package.swift` на известные сетевые, clipboard-, telemetry- и crash-reporting API, а также на подозрительные logging calls.

## Сеть

Исходники не используют `URLSession`, Network.framework, CFNetwork API, WebKit, Sparkle, Sentry, Crashlytics или аналогичные компоненты. В бинарнике нет прямой зависимости от сетевого framework.

Приложение не выполняет:

- проверку обновлений;
- загрузку словарей;
- синхронизацию настроек;
- удалённую активацию;
- отправку диагностических событий;
- отправку crash reports.

macOS и используемые системные framework являются частью операционной системы и существуют вне модели доверия приложения. Для независимой проверки процесса рекомендуется длительный тест через `nettop` или локальный firewall.

## Clipboard

В исходниках отсутствует `NSPasteboard`. Для выделения используется `kAXSelectedTextAttribute`, а для замены — AX set либо Unicode keyboard events. Clipboard остаётся неизменным даже при ошибке преобразования.

## Требуемые разрешения

### Input Monitoring

Системный раздел: **Privacy & Security → Input Monitoring**.

Зачем требуется:

- получать глобальные `keyDown` для построения последнего слова;
- видеть клики мыши и сбрасывать недостоверный контекст;
- замечать новый ввод, пришедший во время короткой коррекции;
- отличать реальные события от синтетических.

Без этого разрешения автоматическое и ручное исправление последнего слова не работают. Menu bar и настройки остаются доступны.

TypeSteady не сохраняет поток событий. Event callback передаёт только текущий компактный snapshot в state machine.

### Accessibility

Системный раздел: **Privacy & Security → Accessibility**.

Зачем требуется:

- получить focused UI element;
- проверить secure text subrole;
- прочитать только текущее выделение;
- заменить выделение без clipboard;
- отправлять события Backspace и исправленный ввод в другое приложение;
- использовать активный event tap для краткого correction gate.

Без Accessibility преобразование выделения и надёжная межпроцессная коррекция недоступны.

### Login Items

При включении «Запускать при входе» используется `SMAppService.mainApp`. macOS может показать TypeSteady в **General → Login Items** и запросить отдельное подтверждение.

Это разрешение даёт только запуск приложения после входа пользователя. Оно не даёт доступа к файлам, сети или другим учётным записям.

### Не требуются

TypeSteady не запрашивает:

- Full Disk Access;
- Screen Recording;
- Camera или Microphone;
- Contacts, Calendars, Photos или Location;
- Apple Events/Automation;
- Files and Folders;
- доступ к clipboard;
- вход в аккаунт или сетевые credentials.

## Защищённые контексты

Коррекция запрещена, если выполняется хотя бы одно условие:

- `IsSecureEventInputEnabled()` возвращает true;
- focused AX element имеет `kAXSecureTextFieldSubrole`;
- frontmost bundle identifier принадлежит известному password manager;
- приложение добавлено пользователем в исключения;
- PID изменился между завершением слова и коррекцией.

Password managers находятся в hard deny и не могут быть включены обратно настройкой. Текущие префиксы включают 1Password/AgileBits, LastPass и Bitwarden.

Ограничение платформы: стороннее приложение может ошибочно не объявить собственное password-поле защищённым. Для таких приложений следует добавить bundle identifier в исключения.

## Защита от изменения чужого текста

Перед удалением выполняются проверки:

- frontmost PID совпадает с PID завершённого токена;
- target input source существует и действительно выбран;
- опасные modifiers отпущены;
- Secure Input не активен.

Клик, навигационная клавиша, смена приложения или неизвестный shortcut уничтожают словесный контекст. Если нельзя доказать положение курсора, приложение отказывается от коррекции.

## Локальная подпись и Gatekeeper

Текущая сборка подписывается ad-hoc с Hardened Runtime. Это обеспечивает целостность bundle после сборки, но не подтверждает личность разработчика и не заменяет нотарификацию Apple.

App Sandbox намеренно не включён: глобальный event tap, межпроцессный Accessibility и синтетический ввод являются основными функциями приложения. Hardened Runtime остаётся включён, но не заменяет sandbox. Поэтому особенно важно собирать приложение из проверенного исходного кода или использовать доверенно подписанный релиз.

Следствия:

- на новой машине Gatekeeper может потребовать **Open Anyway**;
- после пересборки macOS может попросить Input Monitoring/Accessibility повторно;
- публичное распространение требует Developer ID Application, timestamp, notarization и stapling.

Скрипт `Scripts/sign-and-notarize.sh` подготовлен для будущего сертификата.

## Системные crash reports

macOS может локально создавать crash report процесса. TypeSteady:

- не устанавливает crash reporter;
- не читает системные crash reports;
- не прикладывает к ним текст;
- не отправляет их автоматически.

## Отзыв разрешений и удаление

1. Выключить TypeSteady в menu bar.
2. Отключить запуск при входе в настройках либо System Settings.
3. Удалить TypeSteady из Accessibility и Input Monitoring.
4. Завершить приложение.
5. Удалить `.app`.
6. При необходимости удалить preferences домена `local.typesteady.app` штатными средствами macOS или командой `defaults delete local.typesteady.app`.

Удаление preferences уничтожит пользовательские исключения и все настройки.

## Модель угроз и пределы защиты

Архитектура защищает от случайной персистенции, сетевой отправки и коррекции в распознанных secure contexts. Она не может защитить содержимое RAM от процесса с root-доступом, от отладчика с достаточными правами или от уже скомпрометированной macOS.

Поскольку приложение имеет Input Monitoring и Accessibility, устанавливать следует только самостоятельно собранную или доверенно подписанную версию. Перед выдачей разрешений можно проверить подпись и hash артефакта.
