# Бэклог

## Следующий приоритет

- расширить лицензированную локальную частотную базу имён, сленга и сокращений;
- собрать обезличенный офлайн-корпус положительных/отрицательных примеров и измерять precision/recall;
- исправление смешанных слов (`приvet`);
- контекст из одного-двух предыдущих токенов только в RAM;
- отдельные настройки агрессивности по bundle identifier;
- UI для явных пар «исходное → исправление» в пользовательском словаре;
- стресс-harness для воспроизведения десятков тысяч синтетических event-транзакций.

## Интеграции

- плагины Xcode, VS Code и JetBrains для различения кода, строк и комментариев;
- режим Remote Desktop;
- дополнительные языковые профили и словари;
- запоминание раскладки по приложению или окну.

## Доставка

- Developer ID Application;
- Hardened Runtime release configuration;
- нотарификация и stapling;
- воспроизводимый release workflow;
- опциональный подписанный updater как отдельный модуль. Offline-вариант должен оставаться без него.
