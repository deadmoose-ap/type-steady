# Тестирование TypeSteady

## Единая команда

```bash
./Scripts/verify.sh
```

Release gate последовательно запускает полный Swift Testing-набор, встроенный self-test, privacy source check, production-сборку, self-test уже упакованного `.app` и строгую проверку code signature.

## Автоматически покрытые функциональные блоки

| Блок | Проверяемое поведение |
|---|---|
| Пользовательские термины | строки, фразы, компоненты фраз, регистр, Unicode normalization, пробелы, апострофы и дефисы |
| Настройки | значения по умолчанию, сохранение всех пользовательских параметров, восстановление и notification |
| Детектор | раскладка, транслит, пороги, always/never priority, исключённые приложения, password managers, структурные guards и forced proposal |
| Локальные словари | загрузка bundle resources, common/extended score, регистр и Unicode |
| Политика приложений | self-app exclusion, IDE, password managers, URL, email, пути, snake/camel/PascalCase и смешанные идентификаторы |
| State machine | пробелы, пунктуация, неоднозначные клавиши, flush, Backspace, смена приложения, апострофы, дефисы и invalidation |
| Раскладки | определение языка, прямое и обратное отображение, приоритет немодифицированной клавиши и render failure |
| Выделенный текст | оба направления, сохранение неизвестных символов и отказ для непреобразуемого текста |
| Транслитерация | базовые слова, диграфы, регистр, лимит кандидатов и недопустимый ввод |
| Синтез Unicode | chunking BMP/emoji без разрыва surrogate pair |
| Хоткеи | стабильные raw values, Option+Space и производные комбинации выделения |
| Accessibility errors и модели | локализованные ошибки, классификация букв/цифр/границ и названия языков |
| Навигация настроек | полный стабильный набор разделов, уникальные заголовки и системные символы |

## Системные интеграционные границы

Следующие блоки собираются в production-конфигурации, проходят self-test контрактов и privacy gate, но требуют реальной пользовательской сессии macOS:

- `CGEventTap` и захват событий с Input Monitoring;
- `CorrectionCoordinator`, фактическое удаление/повтор клавиш и смена TIS input source;
- `AccessibilityTextService` с конкретными браузерами и редакторами;
- глобальная Carbon-регистрация хоткеев;
- `SMAppService` и Login Items;
- SwiftUI/AppKit menu bar, окно настроек, overlay и TCC-переходы.

Для них обязательна матрица [MANUAL_TESTS.md](MANUAL_TESTS.md). Автотесты намеренно не меняют TCC, активную раскладку, Login Items или ввод пользователя.
