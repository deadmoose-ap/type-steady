# Отличия и преимущества Lang Switcher

## Коротко

Lang Switcher проектируется как локальный macOS-инструмент, а не как кроссплатформенный сервис. Он сочетает агрессивное распознавание ошибочной раскладки с транзакционной заменой текста, не использует буфер обмена для чтения выделения и не содержит сетевого кода.

## Основные отличия от альтернатив

### Полностью локальная работа

- В приложении нет сетевого клиента, телеметрии, рекламных SDK и отправки crash-отчётов.
- Слова обрабатываются в оперативной памяти и не записываются в диагностические логи.
- Используются только встроенные локальные словари, пользовательские исключения и системный словарь macOS.
- Потенциальный updater отделён от основной архитектуры и отсутствует в offline-сборке.

### Выделенный текст без clipboard

Многие небольшие переключатели получают выделение через синтетический Command+C, временно очищают clipboard, а затем пытаются восстановить его. Lang Switcher использует Accessibility API: читает `kAXSelectedTextAttribute`, по возможности записывает результат туда же, а иначе заменяет оставшееся выделение Unicode-вводом. Содержимое clipboard не читается и не изменяется.

### Защита от потери символов

Автокоррекция выполняется как короткая транзакция. Новые печатные события временно удерживаются, раскладка переключается до удаления исходного слова, исправление вводится, после чего удержанные события воспроизводятся в исходном порядке. Синтетические события помечаются и не попадают обратно в анализатор.

### Раскладки определяются динамически

Приложение не полагается на захардкоженную таблицу QWERTY/ЙЦУКЕН. Карта физических клавиш строится из установленных input sources macOS через TIS и `UCKeyTranslate`. Первая версия ограничивает интерфейс парой English ↔ Russian, однако движок изначально оперирует языковыми профилями и допускает добавление новых пар.

### Высокое покрытие без облачной модели

Решение принимает локальный ансамбль: частотные списки, пользовательские правила, системный spell checker, соответствие алфавиту и символьная правдоподобность. Сленг, имена, сокращения и настоящий транслит поддерживаются отдельными слоями, которые можно выключать независимо.

### IDE не выключаются целиком

В редакторах кода автоматическая коррекция становится строже, но ручное исправление остаётся доступным. Движок пропускает URL, пути, email, `camelCase`, `snake_case`, версии и токены с цифрами. Это полезнее глобального deny-list для Xcode, VS Code или JetBrains.

### Приватная диагностика по конструкции

Диагностический API принимает только тип события, длительность, количество символов и код результата. Он не принимает текст и физические последовательности клавиш, поэтому случайно вывести набранное слово через штатный logger невозможно.

## Практическая ценность

- быстрое исправление непосредственно в месте ввода;
- одинаковый механизм для браузеров, мессенджеров, офисных приложений и редакторов;
- мгновенная ручная отмена ошибочного автоисправления тем же хоткеем;
- отсутствие фоновой передачи данных;
- нативный интерфейс, небольшой размер и минимальное число зависимостей;
- понятная деградация: если приложение не предоставляет AX-выделение, Lang Switcher сообщает об этом и не трогает clipboard.
