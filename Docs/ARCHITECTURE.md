# Архитектура

## Поток ввода

`CGEventTap → InputEventTap → InputCoordinator → TypingStateMachine → DetectionEngine → CorrectionCoordinator`.

Callback event tap только фильтрует синтетические события, при активной транзакции удерживает пользовательские события и передаёт компактный снимок на main actor. Работа со словарями, TIS, Accessibility и интерфейсом не выполняется внутри callback.

## Границы модулей

- `Input` не знает о словарях и UI.
- `Layout` строит неизменяемые снимки input sources и выбирает раскладку.
- `Detection` является чистым локальным движком; системный spell checker подключён через протокол.
- `Correction` выполняет preflight, переключение, удаление и воспроизведение.
- `Accessibility` отвечает только за focused element и выделенный текст.
- `System` содержит разрешения, login item, настройки и безопасную диагностику.
- `UI` подписывается на наблюдаемые модели, но не реализует коррекцию.

## Поток данных и приватность

Сырой текст существует только в краткоживущих значениях процесса. Persistent storage получает настройки и пользовательские словарные правила. Diagnostic logger по API не принимает строку слова.
