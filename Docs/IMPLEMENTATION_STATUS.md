# Статус реализации 0.1.0

## Реализовано

- arm64 SwiftPM-проект с deployment target macOS 15;
- menu bar приложение без Dock-иконки;
- SwiftUI-окно настроек;
- динамический выбор English/Russian input sources;
- построение карт клавиш через TIS и `UCKeyTranslate`;
- активный `CGEventTap` с маркировкой синтетических событий;
- буфер текущего и последнего слова, Backspace, смена фокуса и неоднозначная пунктуация;
- локальный детектор: словари, `NSSpellChecker`, script fit, n-grams и структурные guards;
- отдельный детектор фонетического транслита;
- автоматическое и ручное исправление последнего слова;
- кратковременный event gate с воспроизведением ввода, пришедшего во время коррекции;
- отмена последней автоматической коррекции повторным ручным хоткеем;
- AX-преобразование выделения без clipboard и Unicode fallback;
- строгий профиль IDE без глобального запрета редакторов;
- hard deny для password managers, Secure Input и AX secure fields;
- запуск при входе через `SMAppService`;
- звук, локальный overlay и приватная диагностика;
- встроенный self-test, отдельные Swift Testing-тесты и privacy source check;
- ad-hoc подписанная `.app` и скрипт создания `.dmg`.

## Требует ручной проверки

- выдача Accessibility/Input Monitoring в System Settings;
- фактическая замена в Safari/Chromium/Firefox, мессенджерах, Office и IDE;
- поведение сторонних редакторов при Unicode fallback;
- длительный быстрый ввод и переключение фокуса на реальной сессии пользователя;
- отсутствие исходящих соединений процесса при длительном наблюдении через `nettop`;
- login item после переноса приложения в `/Applications`.

## Ограничения версии

- словари являются стартовыми; покрытие увеличивается системным spell checker и пользовательскими правилами;
- смешанные внутри одного слова алфавиты намеренно не исправляются;
- комментарии и строки в IDE не различаются без editor plugins;
- сборка подписана ad-hoc и не нотарифицирована;
- updater и любой сетевой код отсутствуют.
